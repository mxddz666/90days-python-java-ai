# Day 48 · IO 流与文件读写

> 阶段：Java｜Java 基础到 Spring Boot

## 学习目标

- 掌握字节流与字符流

- 理解装饰器模式在 IO 中的应用

- InputStream/OutputStream vs Reader/Writer

## 实践任务

1. 用 BufferedReader 逐行读取文本文件

## 验收标准

- 读取内容完整
- 写入内容正确
- 二进制复制无损坏
