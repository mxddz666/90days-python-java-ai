# Day 57 · Spring MVC 与 REST API

> 阶段：Java｜Java 基础到 Spring Boot

## 学习目标

- 掌握 REST 风格接口设计
- 掌握请求参数与路径变量
- 掌握请求体与响应体

## 今日知识点

- @GetMapping / @PostMapping / @PutMapping / @DeleteMapping
- @PathVariable / @RequestParam / @RequestBody
- @RestController 返回 JSON
- HTTP 状态码与 @ResponseStatus

## 实践任务

1. 实现学生管理的 CRUD REST API
2. 用 POST 提交 JSON 新增学生
3. 测试各接口返回正确状态码

## 验收标准

- 五个接口完整可用
- JSON 收发正确
- 状态码符合 REST 规范
