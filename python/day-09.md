# Day 09 · 函数定义、参数与返回值

> 阶段：Python｜Python 基础到实战

## 学习目标

- 掌握 def 定义函数
- 理解形参与实参、位置参数与关键字参数
- 掌握 return 与默认参数

## 今日知识点

- def func(a, b=1): return a + b
- 位置参数 / 关键字参数 / 默认参数
- return 可返回多个值（元组）
- 函数文档字符串 docstring

## 实践任务

1. 把 bmi.py 改造成 calc_bmi(height, weight) 函数
2. 写函数 max3(a,b,c) 返回三个数最大值，不用内置 max
3. 给函数写 docstring 并用 __doc__ 打印

## 验收标准

- calc_bmi 返回结果正确
- max3 覆盖负数与相等情况
- docstring 能被正确打印
