# Day 50 · 多线程基础

> 阶段：Java｜Java 基础到 Spring Boot

## 学习目标

- 掌握线程创建两种方式
- 掌握线程生命周期
- 理解并发常见问题

## 今日知识点

- 继承 Thread vs 实现 Runnable
- start() 与 run() 的区别
- join / sleep / yield
- 线程状态：NEW/RUNNABLE/BLOCKED/WAITING/TERMINATED

## 实践任务

1. 用 Runnable 创建 3 个线程并观察交替输出
2. 用 join 等待线程结束
3. 用 sleep 模拟耗时任务

## 验收标准

- 线程并发执行
- join 后顺序正确
- 能说出 start 与 run 区别
