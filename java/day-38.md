# Day 38 · this、static 与 final

> 阶段：Java｜Java 基础到 Spring Boot

## 学习目标

- 掌握 this 的用法
- 理解 static 成员与静态块
- 掌握 final 修饰类/方法/变量

## 今日知识点

- this.name = name 解决遮蔽
- static 字段属于类，所有实例共享
- static 方法不能访问实例成员
- final 变量不可重新赋值

## 实践任务

1. 给 Student 加 static school 字段并输出
2. 写一个 static 工具方法
3. 尝试修改 final 变量观察编译错误

## 验收标准

- static 字段共享正确
- 静态工具方法可调用
- final 变量不可变
