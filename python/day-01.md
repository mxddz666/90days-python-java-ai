# Day 01 · Python 环境搭建与第一个程序

> 阶段：Python｜Python 基础到实战｜日期：2026-11-21（周六）

## 学习目标

- 安装 Python 3.11+ 与 VS Code
- 理解解释型语言的 execution 流程
- 写出并运行第一个程序

## 今日知识点

- python.org 下载安装包，勾选 Add Python to PATH
- VS Code 安装 Python 扩展
- 终端执行 python --version 验证
- print() 输出与 # 注释

## 实践任务

1. 创建 hello.py，输出 Hello, 90 Days!
2. 分别用 VS Code 运行按钮和终端 python hello.py 运行
3. 在文件顶部写一行注释说明用途

## 验收标准

- python --version 输出 3.11 以上
- hello.py 两种运行方式都能输出正确文本
- 能说出 print() 的作用
