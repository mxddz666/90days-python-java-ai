# Day 02 · 变量、数据类型与类型转换

> 阶段：Python｜Python 基础到实战｜日期：2026-11-22（周日）

## 学习目标

- 掌握 int / float / str / bool 四种基本类型
- 理解变量命名规则
- 会用 type() 与显式类型转换

## 今日知识点

- 变量赋值与命名规范（下划线命名法）
- type() 查看类型
- int() / float() / str() / bool() 转换
- input() 返回值永远是 str

## 实践任务

1. 写 bmi.py：输入身高(m)与体重(kg)，计算并输出 BMI
2. 用 type() 打印 input 的返回类型
3. 把 BMI 结果转成保留 1 位小数的字符串输出

## 验收标准

- BMI 计算正确（如 1.75/70 => 22.9）
- 能解释为什么 input 需要 int() 转换
- 变量名全部使用下划线命名
